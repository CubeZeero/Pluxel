Pluxel は、After Effects の **スクリプト・エフェクトプラグイン・拡張機能をひとつのライブラリにまとめて保管し、ワンクリックでインストール**できるデスクトップアプリです。バージョンごとに散らばりがちなスクリプトやプラグインを一元管理し、インストール先の記録・更新・アンインストールまで行えます。

## 特長

- **保管** — スクリプト・プラグイン・拡張をドラッグ&ドロップでライブラリに登録
- **自動インストール** — インストール済みの After Effects を自動検出し、種類に応じた正しいフォルダへ配置
- **付随ファイルもまとめて** — `.jsx` に付く `.ffx` プリセットやパネル用画像フォルダなどを同梱して一括インストール
- **更新 / アンインストール** — インストール先を記録し、後から再インストール(更新)や削除が可能
- **複数まとめてインストール** — 選択した複数のアイテムを一度の操作でインストール(管理者権限も 1 回で完結)
- **わかりやすい一覧** — バナー画像・作者・バージョン・タグで aescripts 風に整理
- **バックアップ** — ライブラリ全体を 1 つのパッケージファイル (`.ppf`) に書き出し / 復元

## 対応ファイル形式

| 種類 | 拡張子 | インストール先 |
| --- | --- | --- |
| スクリプト | `.jsx` / `.js` / `.jsxbin` | Scripts |
| ScriptUI パネル | `.jsx` / `.jsxbin` | Scripts › ScriptUI Panels |
| エフェクトプラグイン | `.plugin` / `.aex` | Plug-ins |
| CEP 拡張 | `.zxp` | CEP Extensions |
| インストーラー | `.pkg` / `.exe` / `.msi` | 実行(個別) |

## 使い方

1. スクリプトやプラグインのファイル / フォルダを **ウィンドウにドラッグ&ドロップ**(または上部メニュー **File → 追加**)で登録します。
2. 一覧から項目を選び、詳細パネルで **インストール先(After Effects のバージョン)** を選択します。
3. **インストール** を押すと、種類に応じた正しいフォルダへ配置されます。
4. あとから **更新**(最新ファイルで再インストール)や **アンインストール** が行えます。

> **バックアップ:** 設定ウィンドウからライブラリ全体を `.ppf` ファイルに書き出し、別の環境で読み込んで復元できます。

## 開発

Tauri v2(Rust)+ React / TypeScript で構築しています。

```bash
npm install
npm run tauri dev      # 開発起動
npm run tauri build    # 配布用ビルド (.dmg / .app / .msi / .exe)
```

### テスト

```bash
cd src-tauri && cargo test --lib   # コアロジック (import → export → install) の検証
```
