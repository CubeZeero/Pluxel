# FAQ

Answers to common questions.

??? question "Is Pluxel free?"
    Yes. Pluxel is free and **open-source software under GPL-3.0**. The source
    is available on [GitHub](https://github.com/CubeZeero/Pluxel).

??? question "Which operating systems are supported?"
    **macOS (Apple Silicon)** and **Windows (x64)**. An Intel Mac build is not
    provided at this time.

??? question "Which After Effects versions are supported?"
    Installed After Effects versions are detected automatically. If several are
    installed, you choose the target at install time.

??? question "Do I need administrator privileges (UAC) on Windows?"
    App installation is **per-user**, so it's usually not needed. A UAC prompt
    may appear when writing plugins into After Effects' system folders.

??? question "Do my library and settings get erased when I update the app?"
    No. Data is stored **separately from the app itself**, so it's preserved
    across updates and reinstalls. See
    [Installing the app](usage/install.md) for the location.

??? question "What is a .ppf file?"
    Short for **Pluxel Package File**, a zip under the hood. It bundles scripts
    or plugins with their information (name, author, version, type, etc.), used
    for sharing and backups. See
    [Adding packages](usage/add-package.md) / [Creating packages](usage/create-package.md).

??? question "Can I uninstall what I installed?"
    Yes. From the install history in the detail panel, uninstall per location.
    See [Install & update](usage/install-update.md).

??? question "Where do I report bugs or requests?"
    Please reach out at **cubezeero@gmail.com**.
