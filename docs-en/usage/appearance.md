# Appearance & colors

## Switch between light and dark

Choose **Light / Dark** in Settings.
In v1.2.0, the interface uses a monochrome base.

## Type colors

Use **Type colors** in Settings to distinguish scripts, ScriptUI panels, effects, CEP extensions and installers.
Each type can have its own color.

Adjust hue, saturation and brightness in the custom color picker, or enter a color code.
Use Reset to restore the defaults.
These are personal display settings and are not included in distributed packages.
