# Editing details

Use **Edit (the pencil icon)** in the detail panel to edit an item's
information and file structure.

## What you can edit

- **Name / version / author / homepage / description / tags**
- **Install type** — Script / ScriptUI panel / Effect / CEP extension, etc.
- **Banner image** — change or remove

Press **Save** to confirm or **Cancel** to revert.

## Banner image

Set a banner image to make the list and details easier to read. In edit mode,
choose an image from **Change banner**, or **Remove** it to revert. The
recommended size is shown from the info icon next to the banner.

If you have copied an image, press the **clipboard icon** beside the banner in edit mode to use it.
Copy the image itself; text or an image URL alone is not sufficient.

!!! note "Image and file operations"
    Banner changes and companion file additions or removals apply to the vault when performed.
    Cancelling the metadata form does not undo those operations.

## Adding & removing files

- **Add files / Add folder** — bundle companion files (`.ffx` presets, image
  folders, etc.) later
- Individual files can be removed (the primary asset cannot)
- **Replace files** updates the contents while keeping the same item under management. Edit the version metadata as needed
- PDF manuals and other documentation can be included for storage and distribution, but are not installed into AE
- Folders containing the primary asset are protected from deletion too
- See [Integrity, revisions & history](maintenance.md) to restore an earlier revision

!!! tip "Combine with Update"
    After swapping files, press **Update** in [Install & update](install-update.md)
    to apply the latest files to the installed location.
