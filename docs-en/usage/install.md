# Installing the app

Download the installer for your platform from the [Releases](https://github.com/CubeZeero/Pluxel/releases) page.

=== "macOS"

    For: Apple Silicon (aarch64)

    1. Download `Pluxel_x.y.z_aarch64.dmg`
    2. Open the `.dmg` and **drag Pluxel into your Applications folder**
    3. Launch from Launchpad or Applications

=== "Windows"

    For: 64-bit (x64)

    1. Download `Pluxel_x.y.z_x64-setup.exe`
    2. Run the installer
    3. Launch from the Start menu

## Where data is stored

Your library and settings are stored **separately from the app itself**, so
your registered data is preserved when you update or reinstall the app.

| OS | Location |
| --- | --- |
| macOS | `~/Library/Application Support/com.cubezeero.pluxel/` |
| Windows | `%APPDATA%\com.cubezeero.pluxel\` |
