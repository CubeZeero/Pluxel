# FAQ

よくある質問をまとめました。

??? question "Pluxel は無料ですか?"
    はい。Pluxel は **GPL-3.0 のオープンソースソフトウェア**として無料で公開しています。
    ソースコードは [GitHub](https://github.com/CubeZeero/Pluxel) で確認できます。

??? question "対応している OS は?"
    **macOS(Apple Silicon)** と **Windows(x64)** に対応しています。
    Intel Mac 版は現時点では提供していません。

??? question "対応している After Effects のバージョンは?"
    インストール済みの After Effects を自動検出します。複数のバージョンが
    入っている場合は、インストール時に対象を選べます。

??? question "Windows で管理者権限(UAC)は必要ですか?"
    アプリのインストールは**ユーザー単位**で行うため、通常は不要です。ただし
    プラグインを After Effects のシステムフォルダへ書き込む際に、UAC が
    表示される場合があります。

??? question "アプリを更新するとライブラリや設定は消えますか?"
    消えません。データは**アプリ本体とは別の場所**に保存されるため、更新・
    再インストールしても保持されます。保存場所は
    [アプリのインストール](usage/install.md) を参照してください。

??? question ".ppf ファイルとは何ですか?"
    **Pluxel Package File** の略で、中身は zip 形式です。スクリプトや
    プラグインと、その情報(名前・作者・バージョン・種類など)をまとめた
    ものです。配布やバックアップに使います。詳しくは
    [パッケージの追加](usage/add-package.md) / [パッケージの作成](usage/create-package.md)。

??? question "インストールしたものをアンインストールできますか?"
    できます。詳細パネルのインストール履歴から、インストール先ごとに
    アンインストールできます。詳しくは
    [インストール・更新](usage/install-update.md)。
