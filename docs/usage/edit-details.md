# 詳細の編集

詳細パネルの **編集(鉛筆アイコン)** から、項目の情報やファイル構成を編集できます。

## 編集できる項目

- **名前 / バージョン / 作者 / ホームページ / 説明 / タグ**
- **インストール種別** — スクリプト / ScriptUI パネル / エフェクト / CEP 拡張 など
- **バナー画像** — 変更・削除

編集後は **保存** で確定、**キャンセル** で元に戻ります。

## バナー画像

一覧や詳細を分かりやすくするためのバナー画像を設定できます。編集モードで
**バナーを変更** から画像を選び、**削除** で元に戻せます。推奨サイズは
バナー横の情報アイコンから確認できます。

## ファイルの追加・削除

- **ファイルを追加 / フォルダを追加** — 付随ファイル(`.ffx` プリセットや
  画像フォルダなど)を後から同梱
- 各ファイルの削除も可能(主となるアセットは削除できません)
- **ファイルの置き換え** を行うとバージョンが繰り上がり、同じ項目として
  管理が続きます

!!! tip "更新との組み合わせ"
    ファイルを差し替えたあと [インストール・更新](install-update.md) の
    **更新** を押すと、インストール済みの場所へ最新ファイルが反映されます。
