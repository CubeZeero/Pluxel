# 詳細の編集

詳細パネルの **編集(鉛筆アイコン)** から、項目の情報やファイル構成を編集できます。

## 編集できる項目

- **名前 / バージョン / 作者 / ホームページ / 説明 / タグ**
- **インストール種別** — スクリプト / ScriptUI パネル / エフェクト / CEP 拡張 など
- **バナー画像** — 変更・削除

編集後は **保存** で確定、**キャンセル** で元に戻ります。

## バナー画像

一覧や詳細を分かりやすくするためのバナー画像を設定できます。編集モードで
**バナーを変更** から画像を選び、**削除** で元に戻せます。推奨サイズは
バナー横の情報アイコンから確認できます。

画像をコピー済みの場合は、編集モードでバナー横の **クリップボードアイコン** を押すと、
クリップボードの画像をバナーに設定できます。画像自体をコピーしてください。テキストや画像のURLだけでは設定できません。

!!! note "画像・ファイルの操作"
    バナー変更や同梱ファイルの追加・削除は、その操作時に保管庫へ反映されます。
    編集欄のキャンセルで、これらの操作まで取り消されるわけではありません。

## ファイルの追加・削除

- **ファイルを追加 / フォルダを追加** — 付随ファイル(`.ffx` プリセットや
  画像フォルダなど)を後から同梱
- 各ファイルの削除も可能(主となるアセットは削除できません)
- **ファイルの置き換え** は、同じ項目として管理を続けたまま内容を更新します。バージョン情報は必要に応じて編集してください
- PDFなどの説明書も追加できます。説明書は保管・配布に含まれますが、AEのインストール先へは配置しません
- 本体を含むフォルダも削除対象から保護します
- 差し替え前の版へ戻す方法は [整合性・復元・操作履歴](maintenance.md) を参照してください

!!! tip "更新との組み合わせ"
    ファイルを差し替えたあと [インストール・更新](install-update.md) の
    **更新** を押すと、インストール済みの場所へ最新ファイルが反映されます。
