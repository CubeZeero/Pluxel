# 整合性・復元・操作履歴

保管庫のファイルと、After Effectsへ配置したファイルは別々に管理します。

## インストール済みファイルの整合性

1. 項目の詳細パネルで **整合性をチェック** を選びます。
2. インストール先ごとの結果を確認します。設定の **管理・復元** からは全体を確認できます。

| 結果 | 意味 |
| --- | --- |
| 一致 | インストール時に記録した内容と一致しています |
| 見つかりません | 記録したファイルがありません |
| 変更されています | ファイルの内容や構成などが記録時と異なります |
| 未検証 | 比較用の基準がまだ記録されていません |
| 読み取り不可 | 権限などの理由で確認できません |
| 非対応 | 外部インストーラーなど、配置した内容をPluxelで確認できない形式です |

以前のバージョンでインストールした項目は **未検証** になる場合があります。
再インストールすると基準が記録され、以降の変更や欠損を確認できます。
整合性チェックだけではファイルを修復しません。必要に応じて詳細パネルから更新してください。

## インストール先の競合警告

既存のファイルや、別のパッケージが使用しているパスへ配置するときは、上書き前に警告します。
インストール後に変更されたファイルや、比較基準がないファイルも確認対象です。

- パスと所有元を確認し、上書きするかキャンセルするかを選びます。
- 複数選択したパッケージ同士が同じ配置先を使う場合は、そのまま続行できません。選択内容を変更してください。
- 警告の承認と、OSの管理者権限の確認は別の操作です。

## 保管した旧版への復元

ファイルの差し替えやパッケージ更新などの前に、現在の保管版を自動で退避します。

1. 項目の詳細パネルから **保管庫の過去の版** を開きます。
2. バージョン・保存日時・退避理由を確認し、復元する版を選びます。
3. **この版を保管庫に復元** を押します。
4. 必要なら **記録済みのインストール先にも再インストールする** を選びます。

再インストールを選ばなければ、保管庫だけが戻り、AE側のファイルは変更されません。
復元前の保管版も退避するため、戻し直すことができます。ユーザーのタグと現在のインストール記録は保持されます。
再インストールが中止・失敗した場合も、保管庫の復元結果とインストール先の状態は分けて表示されます。

!!! note "インストーラーの復元"
    `.pkg` / `.exe` / `.msi` は保管しているファイルのみ復元します。
    インストーラーがOSへ導入したソフトウェア自体は戻せません。必要なら復元後に個別に実行してください。

自動退避はライブラリ全体のバックアップの代わりではありません。
別の環境へ移す場合や保管庫自体に備える場合は、[ライブラリ全体のバックアップ](create-package.md)を利用してください。

## 操作履歴

設定の **管理・復元 → 操作履歴** から、読み込み、インストール、更新、アンインストール、
版の復元、ファイル追加・削除などの記録を確認できます。
履歴は新しい順に最大1,000件保存します。履歴の表示自体では操作を取り消しません。
