# スクリプト・プラグインの追加

スクリプトやプラグインを Pluxel のライブラリに登録します。

## 追加する方法

- **ドラッグ&ドロップ** — ファイルやフォルダを Pluxel のウィンドウにドロップ
- **メニューから** — 上部メニュー **File → スクリプト・プラグインを追加**

フォルダごとドロップすると、中身をまとめて 1 つの項目として登録できます。

## 対応ファイル形式

| 種類 | 拡張子 |
| --- | --- |
| スクリプト | `.jsx` / `.js` / `.jsxbin` |
| ScriptUI パネル | `.jsx` / `.jsxbin` |
| エフェクトプラグイン | `.plugin` / `.aex` |
| CEP 拡張 | `.zxp` |
| インストーラー | `.pkg` / `.exe` / `.msi` |

追加時に種類は自動判別されます。判別が正しくない場合は
[詳細の編集](edit-details.md) で「インストール種別」を変更できます。

## 付随ファイルをまとめる

`.jsx` スクリプトには、`.ffx` プリセットやパネル表示用の画像フォルダなどが
付属することがあります。これらを**同じ項目に同梱**しておくと、インストール時に
まとめて配置されます。

- 後から付随ファイルを足したい場合は、詳細パネルの **ファイルを追加 / フォルダを追加** を使います。
- 詳しくは [詳細の編集](edit-details.md) を参照してください。

## スクリプトと ScriptUI パネルの違い

同じ `.jsx` でも、After Effects では **Scripts** に置くものと
**ScriptUI Panels** に置くものがあります。Pluxel は種類を分けて管理し、
それぞれ正しいフォルダへインストールします。
