# パッケージの追加

**`.ppf`(Pluxel Package File)** は、Pluxel でパッケージとして書き出した
ファイルです。中身は zip 形式で、スクリプトやプラグインとマニフェスト情報
(名前・作者・バージョン・種類など)がまとまっています。

## 追加する方法

- **ドラッグ&ドロップ** — `.ppf` ファイルをウィンドウにドロップ
- **メニューから** — 上部メニュー **File → パッケージを追加 (.ppf)**

読み込むと、パッケージに含まれる項目がライブラリに登録され、マニフェストの
情報(バナー画像・作者・バージョン・タグなど)も復元されます。

## パッケージとバックアップ

- 個別のパッケージは `.ppf` として配布・共有できます。
- ライブラリ**全体**をまとめて書き出す場合は
  [パッケージの作成](create-package.md) を参照してください。

!!! tip
    `.ppf` の作り方は [パッケージの作成](create-package.md) で説明しています。
