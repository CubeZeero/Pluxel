# 表示・色の設定

## ライト・ダークを切り替える

設定から **ライト / ダーク** を選びます。
v1.2.0では画面全体をモノクロ基調に整理しました。

## 種別カラー

スクリプト、ScriptUIパネル、エフェクト、CEP拡張、インストーラーを見分けるための色は、
設定の **種別カラー** から個別に変更できます。

独自カラーピッカーで色相・彩度・明度を調整するか、カラーコードを入力します。
初期状態へ戻したい場合はリセットを使います。
これらは自分の表示設定で、配布するパッケージの情報には含まれません。
