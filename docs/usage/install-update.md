# インストール・更新

## After Effects へインストールする

1. ライブラリから項目を選び、詳細パネルを開きます。
2. **インストール先(After Effects のバージョン)** を選びます。
   インストール済みの After Effects は自動検出されます。
3. **インストール** を押すと、種類に応じた正しいフォルダへ配置されます。

| 種類 | インストール先 |
| --- | --- |
| スクリプト | Scripts |
| ScriptUI パネル | Scripts › ScriptUI Panels |
| エフェクトプラグイン | Plug-ins |
| CEP 拡張 | CEP Extensions |
| インストーラー | 実行(個別) |

!!! note "カスタムフォルダ"
    設定で任意のインストール先フォルダを追加すると、After Effects 以外の
    場所へも配置できます。

!!! tip "すべての After Effects へまとめて"
    複数の After Effects を検出している場合、インストール先で
    **「すべての After Effects」** を選ぶと、検出したすべてのバージョンへ
    一度にインストールできます(管理者権限が必要な場合も、確認は原則 1 回)。

## 複数まとめてインストール

複数選択モードで対象を選び、一度の操作でまとめてインストールできます。
管理者権限が必要な場合も、確認は原則 1 回で済みます。

!!! info "インストーラーは個別のみ"
    `.pkg` / `.exe` / `.msi` などのインストーラーは、まとめてではなく
    **個別に実行**します。

## 管理者権限・パスワードについて

After Effects のシステムフォルダなど、**書き込みに管理者権限が必要な場所**へ
インストール(またはアンインストール)する場合は、権限の確認が表示されます。
ホーム以下やカスタムフォルダなど、ユーザーが書き込める場所なら確認は不要です。

=== "macOS"

    v1.2.0以降は、権限付きヘルパーと **Touch ID** を利用できます（macOS 13以降）。

    1. アプリを **/Applications/Pluxel.app** に配置します。
    2. Pluxelの **設定 → 管理者認証 → ヘルパーを設定** を押します。
    3. macOSの **システム設定 → 一般 → ログイン項目と機能拡張** で **Pluxel** を許可します。初回の管理者承認が必要です。
    4. Pluxelで **状態を再確認** し、ヘルパーが **有効** になったことを確認します。

    - 起動後の初回の管理者操作で、Touch IDまたはOSのパスワードで本人確認します。
    - その後は別のパッケージのインストール・更新・削除でも、アプリ終了または手動ロックまで再認証は不要です。
    - ヘルパー方式では認証済みかどうかだけをメモリに保持し、パスワードや生体情報をPluxelに保存しません。
    - **認証セッションをロック** で手動ロック、**ヘルパーを解除** で従来方式に戻せます。

    ヘルパーの管理者書き込み対象は標準AEの **Scripts / Plug-ins**（ScriptUI PanelsやEffects配下を含む）です。
    一括処理のスナップショット上限は **128 MiB** です。保護されたカスタム保存先、CEPを含む混在処理、上限を超える処理は、ヘルパーを解除して従来方式を使ってください。
    ユーザーが書き込める場所には、管理者認証なしでインストールできます。

    ヘルパーを使用しない場合は、管理者パスワードを起動中だけメモリに保持する従来方式を利用できます。
    外部インストーラー（`.pkg`等）の認証は、そのインストーラー側で別途行われることがあります。

=== "Windows"

    **ユーザーアカウント制御(UAC)** の確認ダイアログが表示されます。

    - UAC はパスワードのようにキャッシュできないため、権限が必要な操作ごとに表示されます。
    - **複数まとめてインストール**する場合は、まとめて **1 回の確認**で済みます。

## 更新する

ファイルを差し替えたあとなどに、**更新** を押すと、記録済みのインストール先へ
**最新のファイルで再インストール**されます。

## インストール済みの判定

スクリプト・プラグインは、配置に成功するとインストール先を記録します。
外部インストーラーは起動に成功した時点で「インストール済み」として扱います。
外部インストーラーがOSに導入した内容や、セットアップ完了の有無まではPluxelで確認できません。

## インストール先を確認する

インストール済みの項目では、配置された**絶対パス**が詳細パネルに表示されます。

- **:material-content-copy: コピー** — パスをクリップボードにコピー
- **:material-folder-open: 開く** — Finder(macOS)/ エクスプローラー(Windows)で、
  そのファイルを選択した状態でフォルダを開きます

「その他のインストール先」に並ぶ各インストール先でも同じ操作ができます。

## アンインストール

詳細パネルのインストール履歴から、インストール先ごとにアンインストールできます。
配置したファイルが削除され、記録も消えます。

## 上書き・整合性・旧版への復元

インストール先に既存ファイルや競合がある場合は、上書き前に確認します。
インストール済みファイルの変更・欠損の確認や、旧版の再インストールは
[整合性・復元・操作履歴](maintenance.md) を参照してください。

PDFなどの説明書はAEへ配置しません。macOSでは`.aex`、Windowsでは`.plugin`を保管できても、対応OS以外ではインストールできません。

## 複数選択モード

一覧で複数選択モードにすると、下部に選択件数・解除・インストール・バンドル操作を表示します。
**バンドル操作** を押した後で、新規作成か既存バンドルへの追加かを選びます。
詳しくは [パッケージの作成](create-package.md) を参照してください。
