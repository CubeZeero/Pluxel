# 更新履歴

Pluxel のリリースごとの変更点をまとめます。

## 1.0.1

- インストール先の**絶対パスを表示**(スクリプト・プラグイン等)
- パスの**コピー**、**Finder / エクスプローラーで開く**ボタンを追加
- 狭いウィンドウでフィルタが中途半端に 2 段になる問題を修正
- (Windows)インストール先を開くとドキュメントフォルダが開いてしまう不具合を修正

## 1.0.0 — 初回リリース

- スクリプト・プラグイン・拡張のライブラリ保管(ドラッグ&ドロップ登録)
- After Effects の自動検出と、種類に応じたインストール
- 付随ファイル(`.ffx` プリセット・画像フォルダ等)の同梱インストール
- インストール先の記録による更新 / アンインストール
- 複数選択によるまとめてインストール
- 詳細の編集(名前・バージョン・作者・タグ・バナー画像・インストール種別・ファイル構成)
- パッケージ(`.ppf`)の書き出し / 読み込み、バンドル、ライブラリ全体のバックアップ
- アプリ内自動アップデート(GitHub Releases 連携)
- 日本語 / 英語対応、テーマ・アクセントカラー設定
- macOS(Apple Silicon、署名・公証済み)/ Windows(x64)対応
