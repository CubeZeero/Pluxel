# 更新履歴

Pluxel のリリースごとの変更点をまとめます。

## 1.2.0

### 追加

- macOSのヘルパー方式とTouch ID認証（起動中はパッケージをまたいで認証状態を共有）
- バナー画像をクリップボードから設定
- PDFなどの説明書を同梱（保管・配布用。AEへのインストール対象外）
- 取り込み前の内容確認プレビュー
- インストール済みファイルの整合性チェック
- インストール先の競合・上書き警告
- 保管した旧版への復元と、任意の再インストール
- 操作履歴の表示

### 改善・修正

- モノクロ基調のライト・ダーク表示に整理
- 複数選択バーを簡素化し、バンドル作成・既存への追加をダイアログに集約
- バンドル一覧の検索
- 更新・復元後に編集欄へ古い情報が残る問題を修正
- AE検出後・カスタムインストール先変更後の選択処理を修正
- 本体や本体を含むフォルダの誤削除を防止
- インストール失敗時の復旧と、共有インストール先のファイル管理を改善
- Windowsの取り込み・書き出し時のパス処理を修正
- PPF書き出し失敗時に既存ファイルを保持

新機能の手順は [整合性・復元・操作履歴](usage/maintenance.md)、[詳細の編集](usage/edit-details.md)、[表示・色の設定](usage/appearance.md) を参照してください。

## 1.1.0

- コマンドラインからのPPF作成
- 検出したすべてのAfter Effectsへの一括インストール

## 1.0.1

- インストール先の**絶対パスを表示**(スクリプト・プラグイン等)
- パスの**コピー**、**Finder / エクスプローラーで開く**ボタンを追加
- 狭いウィンドウでフィルタが中途半端に 2 段になる問題を修正
- (Windows)インストール先を開くとドキュメントフォルダが開いてしまう不具合を修正

## 1.0.0 — 初回リリース

- スクリプト・プラグイン・拡張のライブラリ保管(ドラッグ&ドロップ登録)
- After Effects の自動検出と、種類に応じたインストール
- 付随ファイル(`.ffx` プリセット・画像フォルダ等)の同梱インストール
- インストール先の記録による更新 / アンインストール
- 複数選択によるまとめてインストール
- 詳細の編集(名前・バージョン・作者・タグ・バナー画像・インストール種別・ファイル構成)
- パッケージ(`.ppf`)の書き出し / 読み込み、バンドル、ライブラリ全体のバックアップ
- アプリ内自動アップデート(GitHub Releases 連携)
- 日本語 / 英語対応、テーマ・アクセントカラー設定
- macOS(Apple Silicon)/ Windows(x64)対応
